A — Hybrid: CSS Shell + Canvas Interior

Keep the existing HTML/CSS tube structure (rim, glass border, reflections, click handling). Replace only the colored segment interior with a canvas that renders Matter.js fluid particles. A single global canvas overlay paints all tube interiors.

Pros

  • Less rework — keeps glass effects, selection glow, layout
  • Click handling stays in React
  • Easier to roll back if needed

Cons

  • Must sync tube pixel positions → Matter.js world coords each frame
  • Canvas clipping to tube shape needed
  • Two rendering systems to coordinate

B — Full Canvas Rendering

One large canvas covers the entire game board. Matter.js renders everything: tube glass walls, fluid particles, metaball merging, pour stream, tilt animation. HTML elements become invisible click targets laid over canvas positions.

Pros

  • Consistent rendering — no CSS/canvas coordination
  • Physics drives the tube tilt (more natural)
  • Cleaner long-term architecture

Cons

  • Must redraw glass effects, glows, rims on canvas
  • More up-front work (~2× initial effort)
  • Loses Framer Motion spring animations
